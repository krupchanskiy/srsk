## Код Магазина — находки агента (статический разбор)

### Критично
1. Инвентаризация: экран считает разницу от текущего остатка, сервер `shop_apply_inventory` — от снимка `expected_qty` при создании ведомости → продажи между созданием и проведением списываются второй раз (shop-inventory.js:90,160,168,261).
2. Офлайн-очередь кассы: чек, отклонённый при досылке (например, смену закрыли), удаляется навсегда; в payload нет времени продажи и курса — `sold_at` и курс берутся на момент досылки (shop-till.js:127-142, 559).

### Серьёзно
3. Касса: параллельные разборы очереди (online + setInterval + старт) — ложный «отклонён: duplicate key», потеря новой офлайн-продажи при перезаписи массива (till:540-564).
4. Касса: товар исчез из каталога после перезагрузки → TypeError в рисоватьЧек, касса встаёт (till:200,230,245).
5. Касса: Math.ceil(итог/курс/шаг) — плавающая точка, $16 вместо $15 при курсе 90.6 (till:210).
6. Касса: parseFloat('12,5')=12; float-мусор в пожертвовании; дробные рупии (till:202,250,389,490,503,508).
7. Касса: цены и курсы грузятся один раз при открытии страницы; сервер берёт новую цену (till:74-101).
8. Касса на телефоне: шторка чека выше экрана без прокрутки (till.html:56-64).
9. Касса: перерисовка на resize сбивает фокус «Получено» (till:541).
10. Товары: пустая цена сохраняется как 0 (shop-items.js:100).
11. Даты по UTC в базе (`sold_at::date`, `current_date` в курсах) и по часам устройства на страницах (receive:252, analytics:133).
12. Приёмка: новый товар создаётся до проверки остальных строк → сироты и дубли (receive:149-177).
13. Приёмка: поиск названия без учёта вида приёмки → партия без владельца (receive:222).

### Средне
14. Смена: закрытие по устаревшему «ожидается» (shift:309-320).
15. Смена: пожертвования в валюте считаются как рупии (курс 1) (shift:98-124,232).
16. Смена: number-поле перерисовывается на каждый символ (shift:386-392).
17. Касса: скидка фиксируется суммой, не пересчитывается (till:498).
18. Касса: отказ сервера затирает уже набранный новый чек (till:420).
19. Касса: ошибки справочников (остатки, курсы, цели) проглатываются (till:75-86).
20. Возвраты: гонка при открытии чека (returns:43-70).
21. Возвраты: кнопка снова активна после успеха (returns:143-146).
22. Аналитика: гонка периодов; период(7) = 8 дней; пустая дата роняет RPC (analytics:134-153).
23. Инвентаризация: живая «Разница» только на русском (inventory:257).
24. Инвентаризация: «Провести» залипает выключенной; «Начать»/«Удалить» без блокировки (inventory:174-238).
25. Владельцы: «Мастерская» без проверки ошибок и предела 1000 (owners:61-75).
26. Владельцы: гонка «Вернуть непроданное» (owners:176-195).
27. Приёмка: история цен целиком без предела (receive:27).
28. Фото товаров без сжатия, старые не удаляются, ошибка update не проверяется (items:135-146).
29. Изменение товара: update без проверки строк (items:127).

### Мелочи
Отмена чека без блокировки; client_uid-запасной не UUID; дробное количество на кассе; Math.round долга владельцу; replace('%s') со спецсимволами; непереведённые строки и иконки категорий по русским названиям; ошибки на «Смене» игнорируются; касса открывает смену при каждом заходе (p_float 0); till.html utils.js?v=17.
