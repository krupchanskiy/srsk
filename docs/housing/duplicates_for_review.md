# Карточки, требующие разбора — для Нитья-виласини

Обновлено 05.08.2026.

## Зачем это нужно

Когда одной почтой пользуются несколько человек, гостевой портал **не показывает
финансы вообще** — иначе человек мог бы увидеть чужой баланс. Пока такие входы
есть, эти люди не видят в личном кабинете свои платежи и долги.

Каждое утро об этом приходит сообщение в чат. Разберём список — сообщения
прекратятся.

Четыре случая уже закрыты автоматически: там имя, почта и телефон совпадали
полностью, лишняя карточка была пустой — Оксана Цикина, Evelina Galčienė,
Ольга Попова, Jayanti Radhika. Ниже то, что без вас решить нельзя.
