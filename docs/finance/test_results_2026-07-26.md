## Главное изменение в методике

Два раза за два дня одна и та же ошибка доходила до прода: витрина звала
функцию, на которую у роли `authenticated` нет прав (`fin_fmt_money`, чуть не
повторилось с `fin_short_account_name`). SQL-тесты этого не ловили, потому что
я выполнял их от `postgres`, которому можно всё.

Теперь батареи гоняются **под ролью настоящего пользователя**:

```sql
SELECT set_config('request.jwt.claims', json_build_object('sub', <uid>, 'role','authenticated')::text, true);
SET LOCAL ROLE authenticated;
```

Это сразу подсветило и обратное: тест не может читать `tg_chat_links`,
`fin_accounts`, `fin_categories` напрямую — и правильно, интерфейс их тоже не
читает, только через витрины. Пришлось переписать проверки так, как их видит
страница, — что само по себе честнее.
